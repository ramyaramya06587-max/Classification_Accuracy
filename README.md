
# Task 38: Classification Accuracy

## Objective
To calculate the accuracy of a classification model and compare predicted values with actual target values.

## Dataset
Iris Dataset from Scikit-learn.

The dataset contains:
- 150 samples
- 4 numerical features
- 3 flower classes

## Tools and Technologies
- Python
- Pandas
- Scikit-learn
- Jupyter Notebook

## Implementation Steps
1. Import the required libraries.
2. Load the Iris dataset.
3. Separate features and target values.
4. Split the dataset into training and testing sets.
5. Train a Decision Tree Classification model.
6. Predict the target values.
7. Compare actual and predicted values.
8. Calculate classification accuracy.
9. Interpret the model performance.

## Evaluation Metric

Accuracy measures how many predictions are correct compared to the total number of predictions.

Formula:

Accuracy = (Correct Predictions / Total Predictions) × 100

## Results
- Actual and predicted values are compared.
- Accuracy score is calculated using `accuracy_score()`.
- Accuracy is also displayed as a percentage.
- Model performance is interpreted based on the accuracy.

## Conclusion
Successfully implemented a basic classification model using the Iris dataset. Compared actual and predicted values and evaluated model performance using classification accuracy.
